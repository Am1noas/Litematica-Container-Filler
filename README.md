这是一个Litematica辅助模组，一键填充投影容器

对着缺失物品的容器按下快捷键，模组会自动从你的背包或潜影盒中提取所需材料并填入。按下 **`L + C`** 即可打开全中文配置菜单，自由调整容器高亮和填充延迟。

**运行依赖**：Fabric API, MaLiLib, Litematica
