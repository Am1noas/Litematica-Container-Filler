一个 Litematica 辅助模组，一键填充投影容器

### 功能
* **智能装填**：自动从背包或快捷潜影盒中提取材料并填入投影种缺失物品的容器
* **双模式切换**：准星和范围两种填充模式

### 运行依赖
* **Minecraft**
* **Fabric API**, **MaLiLib**, **Litematica**
